# テスト計画・確認記録

## 1. 受入テスト

| ID | 前提・操作 | 期待結果 |
|---|---|---|
| AT-01 | ホームを開く | 練習、Reading模試、各結果へのリンクが表示される |
| AT-02 | 練習を開きPart 5を選択 | Part 5問題が表示される |
| AT-03 | 練習を開きPart 6/7を選択 | 本文セット、文書順、発信者、設問が対応して表示される |
| AT-04 | 有効なA～D回答を送信 | サーバーで採点され、履歴が1行追加され、詳細結果へ遷移する |
| AT-05 | 不正な回答値または問題IDでPOST | 400となり、履歴は不正に作成されない |
| AT-06 | 問題を誤答してから練習一覧を開く | 最新誤答の問題が通常問題より先に表示される |
| AT-07 | 同じ問題に正答してから練習一覧を開く | 最新正答となり誤答優先対象から外れる。旧履歴は残る |
| AT-08 | 模試を開始 | 100問、Part構成30/16/54、75分タイマーが表示される |
| AT-09 | 模試を再読み込み | 同一セッション内で同じ問題セットと開始時刻が使われる |
| AT-10 | 模試を任意回答で提出 | 回答・正答・誤答・未回答の合計が100となり、結果が保存される |
| AT-11 | 75分経過後に提出 | サーバー側集計では全問未回答として扱われる |
| AT-12 | 練習・模試結果を開く | 直近最大100件と選択した結果詳細が表示される |
| AT-13 | 各結果画面からCSVを取得 | UTF-8 BOM付きCSVが得られ、列数・値が正しい |
| AT-14 | DB停止または誤設定で画面にアクセス | 成功扱いにせずエラーが確認できる |
| AT-15 | EclipseでClean/Publish/再起動後にアクセス | 旧404が解消し、上記画面・Servletが配備される |

## 4. テスト実施手順

1. DBをバックアップし、テスト用DBまたは復元可能な状態を用意する。
2. 現在のDBに必要なテーブルと問題データがあることを確認する。
3. EclipseでプロジェクトをCleanし、TomcatへPublishしてサーバーを再起動する。
4. ホーム、練習、誤答優先、回答履歴、模試、結果一覧、CSVの順に確認する。
5. テスト用の練習履歴・模試結果が残った場合、IDと対象を特定し、承認された方法でのみ削除する。
6. 実施日、環境、データ件数、結果、障害、再試験結果を本書へ記録する。

## 5. 合格条件

- すべての必須受入テストがPassであること。
- 模試の総問題数が100、内訳が30/16/54、結果の内訳合計が100であること。
- DB書き込みの再読込、履歴の最新正誤判定、CSV出力を確認できること。
- Eclipse管理Tomcat上で対象ルートの404が解消していること。
- DB接続情報・個人情報・実パスワードがログや提出資料へ出力されていないこと。
