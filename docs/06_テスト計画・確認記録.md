## 4. テスト実施手順

1. DBをバックアップし、テスト用DBまたは復元可能な状態を用意する。
2. 現在のDBに必要なテーブルと問題データがあることを確認する。
3. EclipseでプロジェクトをCleanし、TomcatへPublishしてサーバーを再起動する。
4. ホーム、練習、誤答優先、回答履歴、模試、結果一覧、CSVの順に確認する。
5. テスト用の練習履歴・模試結果が残った場合、IDと対象を特定し、承認された方法でのみ削除する。
6. 実施日、環境、データ件数、結果、障害、再試験結果を本書へ記録する。

## 5. 合格条件

- すべての必須受入テストがPassであること。
- 模試の総問題数が100、内訳が30/16/54、結果の内訳合計が100であること。
- DB書き込みの再読込、履歴の最新正誤判定、CSV出力を確認できること。
- Eclipse管理Tomcat上で対象ルートの404が解消していること。
- DB接続情報・個人情報・実パスワードがログや提出資料へ出力されていないこと。

## 6. 今回確認できなかった理由

資料作成時のDB接続試行は認証時に失敗しました。現在のDBサーバー、認証方式、設定値を推測して変更せず、利用者の環境で接続先と安全な認証設定を確認してから再試験してください。
