# DB設計書（論理設計・要DDL確認）

## 1. 注意事項

本書はJava DAOのSQL・結果マッピングから読み取った論理項目です。今回、実DBのDDLを取得できていないため、カラムの正確な型、長さ、NULL許容、初期値、主キー、外部キー、インデックス、照合順序を確定仕様として記載していません。導入・移行時はMySQLで実DDLを確認し、本書を更新してください。

接続先や認証情報の実値は本書に記載しません。DB接続情報はコードに埋め込まず、環境別の安全な設定へ移行してください。

## 2. テーブル一覧

| テーブル | 役割 | コードから確認できる主キー相当 |
|---|---|---|
| `questions` | Part 5～7の設問・選択肢・正答 | `question_id` |
| `passage_groups` | Part 6/7の本文セット | `group_id` |
| `passage_group_items` | 本文セット内の各文書 | `item_id` |
| `learning_history` | 練習回答の追記履歴 | `history_id` |
| `mock_exam_results` | 模試単位の結果集計 | `mock_id` |

## 3. 論理項目

### 3.1 `questions`

| 項目 | 用途・参照箇所 |
|---|---|
| `question_id` | 設問ID。練習回答、結果、模試回答キーで利用 |
| `group_id` | 本文グループID。単独設問はNULLを許す設計としてコードが扱う |
| `sequence_no` | グループ内の設問順 |
| `part_type` | Part番号（対象は5、6、7） |
| `question_text` | 設問文 |
| `option_a`～`option_d` | 選択肢 |
| `correct_answer` | 正答記号 |
| `explanation` | 解説 |

### 3.2 `passage_groups`

| 項目 | 用途 |
|---|---|
| `group_id` | 本文セットID |
| `part_type` | Part番号 |
| `group_type` | SINGLE/DOUBLE/TRIPLE等の本文形式 |
| `title` | 本文セットのタイトル |

### 3.3 `passage_group_items`

| 項目 | 用途 |
|---|---|
| `item_id` | 本文行ID |
| `group_id` | 所属する本文セット |
| `sequence_no` | セット内の文書表示順 |
| `speaker` | 文書の発信者・種類を示す見出し |
| `text_body` | 文書本文 |

### 3.4 `learning_history`

| 項目 | 用途 |
|---|---|
| `history_id` | 回答履歴ID。最大値を最新履歴判定に使用 |
| `question_id` | 回答した設問 |
| `user_answer` | 利用者の回答記号 |
| `is_correct` | 回答の正誤 |
| `answered_at` | 回答日時。履歴一覧・CSVに利用 |

履歴は1回答につき1行追加されます。練習出題時に問題ごとの最新 `history_id` を取得し、その `is_correct` がFALSEなら優先出題します。したがって、IDの単調増加が最新判定に使えるDB定義であることをDDL確認してください。

### 3.5 `mock_exam_results`

| 項目 | 用途 |
|---|---|
| `mock_id` | 模試結果ID |
| `start_time` / `end_time` | 模試開始・終了日時 |
| `total_questions` | 総問題数（現行仕様は100） |
| `answered_count` | 回答済み数 |
| `correct_count` | 正答数 |
| `incorrect_count` | 誤答数 |
| `unanswered_count` | 未回答数 |

模試ごとの設問IDや回答内容を格納する項目は現行DAOから確認できません。模試履歴の問題別復習を実装する場合は、別途模試セッション・回答明細テーブルを設計してください。

## 4. 論理関連

```text
passage_groups 1 ─── * passage_group_items
       │
       └────────── * questions（本文グループを持つ設問）

questions 1 ─────── * learning_history

mock_exam_results（模試単位の集計。設問明細との関連は未実装）
```

上記の関連はアプリケーションが利用する論理関係です。実DBの外部キー制約が存在することを意味しません。

## 5. 主な読み書き

| 処理 | 読み書き |
|---|---|
| 練習問題一覧 | `questions`、誤答優先時は最新 `learning_history` |
| 本文表示 | `passage_groups`、`passage_group_items` |
| 練習回答 | `questions`を再読込し正答判定、`learning_history`へINSERT |
| 練習結果一覧 | `learning_history` JOIN `questions` |
| 模試開始 | `questions` JOIN `passage_groups`、本文表示時に本文テーブル参照 |
| 模試結果登録 | `mock_exam_results`へ集計INSERT |
| 模試結果一覧 | `mock_exam_results` |
| CSV | 練習・模試各テーブルを全件取得 |
